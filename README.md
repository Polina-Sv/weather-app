# 🌦 Прогноз погоды

Веб-приложение для просмотра текущей погоды, почасового и недельного прогноза по любому городу мира. Построено на React, данные берутся из открытого API [Open-Meteo](https://open-meteo.com/) — без необходимости регистрации и API-ключа.

Вдохновлено челленджем [Frontend Mentor: Weather app](https://www.frontendmentor.io/challenges/weather-app-K1FhddVm49).

## Демо
[Посмотреть на GitHub Pages]()

## Функциональность

- 🔍 Поиск города с автодополнением (геокодинг через Open-Meteo)
- 🌡 Текущая погода: температура, ощущается как, влажность, ветер, осадки
- ⏱ Прогноз на 24 часа
- 📅 Прогноз на 7 дней
- 🔄 Переключение единиц измерения: °C / °F, км/ч / мили/ч
- 🎨 Иконки погоды в виде SVG (солнце, облачно, дождь, снег, гроза и т.д.)

## Технологии

- [React](https://react.dev/) — интерфейс приложения
- [Webpack](https://webpack.js.org/) — сборка проекта
- [Babel](https://babeljs.io/) — транспиляция JSX и современного JS
- [Open-Meteo API](https://open-meteo.com/) — данные о погоде и геокодинг

## Установка и запуск

1. Клонируй репозиторий:
   ```bash
   git clone https://github.com/твой-логин/weather-app.git
   cd weather-app
   ```

2. Установи зависимости:
   ```bash
   npm install
   ```

3. Запусти проект в режиме разработки:
   ```bash
   npm start
   ```
   Приложение откроется по адресу [http://localhost:3000](http://localhost:3000)

4. Чтобы собрать финальную версию для публикации:
   ```bash
   npm run build
   ```
   Результат появится в папке `dist/`.
